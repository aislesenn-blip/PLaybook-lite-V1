# Database & Logic Audit: Playbook Lite v1.0

## 1. The Database Schema (Supabase)

Based on the current codebase scan, here is the **exact SQL** required to support the frontend operations.

### **Table: `parents`**
**Usage:** Stores the mobile number of parents who sign up via the Landing Page.
**Location in Code:** `src/lib/supabaseClient.ts` -> `saveParentData()`

```sql
-- create the parents table
CREATE TABLE public.parents (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    mobile_number TEXT NOT NULL
);

-- enable RLS (Row Level Security)
ALTER TABLE public.parents ENABLE ROW LEVEL SECURITY;

-- create a policy to allow anyone to insert (since it's a public landing page)
CREATE POLICY "Enable insert for all users" ON public.parents
    FOR INSERT WITH CHECK (true);

-- create a policy to allow reading (optional, depends on admin needs)
CREATE POLICY "Enable read access for all users" ON public.parents
    FOR SELECT USING (true);
```

### **Table: `license_keys` (Logic Note)**
**Critical Finding:** The current implementation of `unlockPremium` in `src/lib/subscriptionLock.ts` checks a **hardcoded string** (`PLAYBOOK-LITE-VIP`) and does **NOT** query a Supabase table.
**Recommendation:** To enable dynamic license keys, you must create this table and update `subscriptionLock.ts` to query it.

```sql
-- (Optional) If you upgrade to server-side validation
CREATE TABLE public.license_keys (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    key_code TEXT NOT NULL UNIQUE,
    is_active BOOLEAN DEFAULT TRUE,
    child_name TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
```

## 2. The "Velvet Rope" Logic (Lock System)

### **How it Works**
The application uses a **Client-Side Time Lock** based on `localStorage`.

1.  **Initialization:**
    - On first load, `src/lib/subscriptionLock.ts` checks for `localStorage.getItem('firstOpenDate')`.
    - If missing, it sets `Date.now()`.

2.  **The Check (Every App Launch):**
    - It calculates `hoursElapsed = (Date.now() - firstOpenDate) / (1000 * 60 * 60)`.
    - It checks `localStorage.getItem('isPremium')`.
    - **Condition:** If `hoursElapsed > 48` AND `isPremium !== 'true'`, the user is redirected to `/locked`.

3.  **Unlocking (The Key):**
    - The user enters a key in `LockScreen.tsx`.
    - The code calls `unlockPremium(key)`.
    - **Logic:** It strictly compares `key === 'PLAYBOOK-LITE-VIP'`.
    - **Result:** If match, `localStorage.setItem('isPremium', 'true')` is set, permanently unlocking the app.

## 3. The "Brain" (AI & Math)

### **A. Whisper AI (Speech Recognition)**
-   **Library:** `@xenova/transformers` running in a **Web Worker** (`src/workers/whisper.worker.ts`).
-   **Model:** `Xenova/whisper-tiny`.
-   **Loading:**
    -   First Run: Fetches model weights (~40MB) from Hugging Face CDN.
    -   Subsequent Runs: Loads from browser Cache Storage (Offline capable *after* first load).
-   **Execution:** Audio processing happens off the main thread to prevent UI freezing.

### **B. Physics Engine (Math Lessons)**
-   **Library:** `matter-js`.
-   **Integration:** `src/components/App/PhysicsScene.tsx`.
-   **Status:** **Fully Functional**.
    -   It initializes a `Matter.Engine` and `Matter.Render`.
    -   It creates static boundaries (Ground, Walls).
    -   It spawns dynamic `Bodies.circle` objects with numbers (`1` or `2` based on Day ID) that react to gravity and collisions.
    -   It includes `MouseConstraint` to allow children to grab and throw the numbers.
